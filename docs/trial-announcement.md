## 試してほしいこと

1. 来場者: 入場 → 相談を選んで整理券を取る → 目安時間が出る
2. スタッフ: コードでログイン → 担当の列で「次を呼ぶ」→ 来場者側に呼出通知（バナー・振動）が出る
3. 来場者: 「いま向かいます」→ スタッフ: 相談開始 → 完了（5秒間は取り消し可）
4. 不在 → 復帰
5. 画面の見づらい点・文言・押しにくさ（スマホ実機、iOS／Android 両方だとありがたい）
