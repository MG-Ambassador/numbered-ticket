## 試してほしいこと

1. 来場者: 入場 → 相談を選んで整理券を取る → 目安時間が出る
2. スタッフ: コードでログイン → 担当の列で「次を呼ぶ」→ 来場者側に呼出通知（バナー・振動）が出る
3. 来場者: 「いま向かいます」→ スタッフ: 相談開始 → 完了（5秒間は取り消し可）
4. 不在 → 復帰
5. 画面の見づらい点・文言・押しにくさ（スマホ実機、iOS／Android 両方だとありがたい）

## 運用担当者向け（配布しない）

- 管理者は運営ID＋パスワード（TOTP なし）。ロールは開発者・責任者・教員・アンバサダー・スタッフ。職員に配るなら「スタッフ」（確認と受付の切り替えだけ）か「教員」「アンバサダー」（アカウント管理以外）が目安
- 最初のアカウントは手元で作る: `gcloud auth application-default login` のあと `node scripts/create-operator.mjs --project oc-ticket-2027 --login-id <運営ID> --display-name <表示名> --role owner --execute`。表示された仮パスワードを本人に直接伝える（配布物には載せない）。以降の職員のアカウントは、管理画面の「アカウント」から作れる
- **この仕組みは PR をマージして本番にデプロイするまで有効にならない**。デプロイの前に、実行サービスアカウントへ `roles/iam.serviceAccountTokenCreator` を付けること（手順は docs/p4-integration.md の「運営アカウント」）。付け忘れると全員ログインできない。切り替えると、以前のメール/パスワード＋TOTP の管理者は入れなくなる
- 匿名ログインの上限は 12:30〜16:30 JST のみ 1000件/時に引き上げ済み
- 本番プロジェクト: `oc-ticket-2027`（Firebase、asia-northeast1）
